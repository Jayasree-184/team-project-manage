# UI/UX refinement audit

The current product direction is a strong editorial command-center dossier: parchment/concrete ground, black rulework, serif display type, monospace operator labels, and rust as the controlled signal color. The public landing already has a clear scene system and oversized typography. The authenticated shell has the correct two-column structure and role-aware navigation, but shared application surfaces can be tightened with stronger section markers, more consistent panel headers, clearer form group rhythm, better status semantics, and more intentional loading/empty/error states. The login view is visually coherent but can carry a stronger Atlas Office operator/register motif. The refinement must preserve existing tRPC data flows, auth boundaries, direct routes, and the Three.js reduced-motion fallback.

Suggested visual priorities: create a reusable register header pattern, sharpen panel padding and border hierarchy, improve sidebar brand/status treatment, make table headers and row metadata more legible, unify buttons/fields/badges, and add a consistent artifact motif such as `TPM / 01`, section numbers, and status ledger marks across app pages.
